# Planning Documents

Use this directory for tracked planning documents that should remain available to future sessions.

## Directory Layout

- `current/`: Active plans with unchecked work, open decisions, or execution state that future sessions should continue.
- `history/`: Finished plans, accepted designs, and archived planning records that explain past decisions but no longer drive current work.

## Workflow

Create new tracked plans in `docs/plans/current/` with a date-prefixed filename. Move a plan to `docs/plans/history/` when the work is complete, superseded, or no longer active.

Use `docs/research/` for gitignored source gathering, tool evaluations, and private research notes. Use `.agents/memory/` for local session memory that should not become a durable repo record.
