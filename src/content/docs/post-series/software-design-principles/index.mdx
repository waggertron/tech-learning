Choose a lesson by the failure you are trying to prevent. These articles form a collection, not a prerequisite sequence.

## Worked lessons

- [SOLID and composition through a changing report feature](../../2026-04-24-solid-principles/), separate report rules from delivery, add auditing without a subclass matrix, and test behavioral substitution.
- [TypeScript async mutex](../../2026-05-15-typescript-async-mutex-pattern/), serialize async writes when two operations can interleave across an `await`.

The report example isolates behavior that changes independently. The mutex example addresses a different problem: several correct operations that interfere when they share mutable state. Neither design principle nor class structure alone establishes a concurrency guarantee.
