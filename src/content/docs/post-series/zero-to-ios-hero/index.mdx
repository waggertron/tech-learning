Start with Swift exercises, then follow Field Notes through product design, SwiftUI, UIKit, architecture, and testing. Read the implementation evidence on each lesson: package execution, Apple SDK compilation, Simulator checks, and physical-device checks establish different things.

The core notebook path is separate from the reference guides and optional project assignments below. The design briefs describe proposed products, not completed applications.

## Core reading order

### Orientation and tools

1. [Zero to iOS Hero 1: The Apple development map](../../2026-07-16-apple-development-map/), Swift, Xcode, SDKs, frameworks, targets, schemes, Simulator runtimes, and devices placed into one development map.
2. [Zero to iOS Hero 2: Xcode, simulators, devices, and Git](../../2026-07-16-xcode-simulators-devices-git/), The path from an Xcode project to simulated and physical destinations, with signing, diagnostics, Derived Data, and the first Git checkpoint.
3. [Zero to iOS Hero 3: Learn by building and debugging](../../2026-07-16-learning-by-building-debugging/), A prediction-first Swift debugging loop using compiler diagnostics, assertions, LLDB breakpoints, variable inspection, logs, documentation, and small experiments.

5. [Zero to iOS Hero 5: Operators, conversion, and overflow](../../2026-07-16-swift-operators-conversion-overflow/), Build typed expressions, convert numeric values deliberately, clamp a score, and distinguish checked arithmetic from wrapping overflow.
6. [Zero to iOS Hero 6: Control flow, ranges, and patterns](../../2026-07-16-swift-control-flow-patterns/), Express decisions and repetition with if, switch, loops, ranges, where clauses, and Swift pattern matching.

8. [Zero to iOS Hero 8: Optionals and absence](../../2026-07-16-swift-optionals-absence/), Represent missing values explicitly and choose among optional binding, guard, chaining, nil coalescing, propagation, and force unwrapping.
9. [Zero to iOS Hero 9: Collections, sequences, and cost](../../2026-07-16-swift-collections-sequences-cost/), Choose arrays for order, dictionaries for keyed lookup, sets for uniqueness, and lazy sequences when deferred work matches consumption.
10. [Zero to iOS Hero 10: Strings, Unicode, and formatting](../../2026-07-16-swift-strings-unicode-formatting/), Treat Swift text as Unicode grapheme clusters, normalize search keys deliberately, use String.Index, and format dates and measurements at display boundaries.
11. [Zero to iOS Hero 11: Structures and value semantics](../../2026-07-16-swift-structures-value-semantics/), Model a Field Note as a structure, distinguish stored values from instances, and prove that editing one copy leaves the original unchanged.
12. [Zero to iOS Hero 12: Enumerations, associated values, and pattern matching](../../2026-07-16-swift-enumerations-associated-values-pattern-matching/), Replace contradictory loading flags with one exhaustive Swift enumeration whose cases carry only the data each state needs.
13. [Zero to iOS Hero 13: Classes, identity, inheritance, and type casting](../../2026-07-16-swift-classes-identity-inheritance-type-casting/), Use a shared editing session to distinguish reference identity from value equality, then keep inheritance and runtime casting inside deliberate boundaries.
14. [Zero to iOS Hero 15: Closures, function types, capture, and higher-order operations](../../2026-07-16-swift-closures-function-types-capture-higher-order-operations/), Pass Field Notes behavior as typed values, compose collection operations, and make closure capture and lifetime choices visible.

[Zero to iOS Hero 16: Protocols, extensions, and protocol-oriented design](../../2026-07-16-swift-protocols-extensions-protocol-oriented-design/), Define a small Clock capability, supply deterministic and composed implementations, and choose carefully between generics, existentials, and default behavior.
17. [Zero to iOS Hero 17: Errors, Result, throwing APIs, and recovery](../../2026-07-17-swift-errors-result-throwing-recovery/), Model import failures as typed values, map transport details at a boundary, preserve deferred outcomes with Result, and choose recovery from the failure contract.
18. [Zero to iOS Hero 18: Generics, associated types, existentials, and opaque types](../../2026-07-17-swift-generics-associated-types-existentials-opaque-types/), Build a generic page and protocol-backed note source while preserving type relationships across constraints, associated types, existentials, and opaque returns.

20. [Async and await, tasks, groups, cancellation, and continuations](../../2026-07-18-swift-async-await-tasks-groups-cancellation-continuations/), Load note assets with structured child tasks, propagate cancellation, and bridge one callback without losing its completion contract.

## Practice and evidence

The standard-library Swift exercises run in the browser only when an execution service is available. Their Linux environment cannot import Apple frameworks. The Field Notes companion provides source and package tests; each app lesson records which Apple-target checks have actually run.

Use the package setup instructions linked from the capstone. An unverified Apple target remains unverified even when the package tests pass. Reference guides help choose a capability and its validation surface without implying that every framework has been integrated.
