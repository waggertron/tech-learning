# Journal fonts

Self-hosted Latin WOFF2 subsets, downloaded on 2026-11-09. Both families use the SIL Open Font License; their license files are included here.

- Newsreader, variable weight 400-700, optical size 6-72: https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjA.woff2
- Source Sans 3, variable weight 400-700: https://fonts.gstatic.com/s/sourcesans3/v20/nwpStKy2OAdR1K-IwhWudF-R3w8aZQ.woff2
- Newsreader license: https://raw.githubusercontent.com/google/fonts/main/ofl/newsreader/OFL.txt
- Source Sans 3 license: https://raw.githubusercontent.com/google/fonts/main/ofl/sourcesans3/OFL.txt

The CSS uses system fallbacks for characters outside the Latin subset. No font service request is made when reading the site.
